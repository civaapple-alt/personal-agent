# Personal Agent 0.8.3

0.8.3 是 `0.8.x` LTS 候选基线的首个维护补丁版本，**完全保持 `0.8.x` 冻结的三环契约、角色定义与 `.data/` 存储布局向后兼容**。本版聚焦发起事项与 `@成员` 主责统筹协作体验、工作区隔离与 Pi 信任集成、Skill 提案预览与工作区级托管、DTO/SSE 契约收敛以及若干工作台交互细节打磨。

## 本版变化

- **主责统筹 `@成员` 协作与发起事项面板精简**：
  - 已有业务主责的事项中，对话流输入框 `@单个或多个 AI 成员`（如同一条消息中同时 `@Engineering Manager` 派活与 `@QA Manager` 独立核查）统一先交由事项主责带着完整上下文通过 `delegate_to_member` 按序统筹并汇总回复，当轮自动放行显式 `@` 成员的委托权限，并继续支持为核查岗位配置独立模型实现跨模型验证；新增实机冒烟验证脚本 `npm run demo:mention-verify`。
  - 精简新建事项面板 `MatterInitiationPanel`：聚焦「主责」与开关式「允许委托」成员选择（单人本机模式自动隐藏多余的组织范围/人类成员行，旁听与复核按需在事项内调整）；将新事项主责持久化到 `#/chats/new/<memberId>`，刷新页面不再丢失所选角色；清理历史 `wechat-*` CSS 类名为 `roster-*`。
  - 角色架构师澄清问题复用 `@pa/contracts/human-decision` 的 `Clarification`（`{ question, options?, context? }`），支持在 `FloatingClarificationDock` 中直接点选编号选项。
- **工作区隔离、Pi 信任与 CLI 参数透明化**：
  - 未绑定工作区的通用事项收敛到独立默认工作区 `~/.pa/workspaces/default`（支持 `PA_DEFAULT_WORKSPACE_DIR` 覆盖），避免误落入 `personal-agent` 源码仓并继承其 `AGENTS.md`。
  - 集成 Pi 原生 `~/.pi/agent/trust.json`：本机个人模式下显式选定的本地业务仓库自动传入 `--offline --approve`（尊重显式拒绝记录），并在工作区详情面板提供 `Pi 信任` 开关（克隆仓保持隔离）；系统文档补充 PA 实际传给 Pi 的完整 CLI 参数说明。
- **工作区 Skill 集中托管与预览升级**：
  - `workspace` 作用域的 `propose_skill` 产出集中存放在 `.data/skills/workspaces/<workspaceId>/<name>/`，不污染业务 Git 工作区，并经 `--skill` 与 `PA_MANAGED_SKILL_ROOTS` 自动挂载；显式批准的 Skill 提案默认应用为 `autonomous` 信任。
  - `SkillProposalCard` 升级为分栏文件树 + Markdown 渲染/源码只读弹窗（展示完整 YAML frontmatter），同步完善 `skill-design` 与 `pa-trust-capture` 的先澄清后抽象引导。
- **契约统一与工作台体验修复**：
  - 统一前后端 `Matter` / `MatterMessage` DTO 与 SSE `/api/events` 契约（`@pa/contracts/matter`、`@pa/contracts/sse-events`），新增 `docs/concepts/future-proposals.md` 收纳 `0.9.x+` 演进提案，明确 `0.8.x` LTS 补丁边界。
  - 修复浏览器走查回归（`org_viewer` 权限门控、头像色板对齐、`#/spaces` 路由别名、1072px 顶栏防重叠、`pi-default` `antiJobs` 分隔与启动横幅角色计数）。
  - 细节打磨：工具与 Skill 记录默认保持紧凑 1 行、鼠标悬停展开最多 4 行（`bash` 摘要放宽至 320 字符）；用户消息与 AI 回复新增一键复制按钮；模型选择器点击模型后自动同步顶部「供应商」与「搜索模型」显示。

## 安装与升级

从 [GitHub Release](https://github.com/civaapple-alt/personal-agent/releases/tag/v0.8.3) 下载发布包。需要 Node.js 22.19 或更高版本和 Git；执行 AI 任务还需要安装并配置 Pi CLI。

| 文件 | 使用方法 |
| --- | --- |
| `personal-agent-0.8.3-prebuilt.tar.gz` | 解压后运行 `node apps/cli/dist/main.js` |
| `personal-agent-0.8.3-source.tar.gz` | 解压后运行 `npm ci` 和 `npm run start:web` |
| `SHA256SUMS` 和 `manifest.json` | 核对下载文件和发布提交 |

**从 0.8.2 / 0.8.1 / 0.8.0 / 0.7.x 升级**：可直接复用已有 `.data/` 数据目录，无需手工迁移。

安装步骤见[首次运行教程](../tutorials/getting-started.md)。
