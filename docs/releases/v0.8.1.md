# Personal Agent 0.8.1

0.8.1 沿着「顺着 Pi 纹理生长」原则，完成**信任四步（步骤 3 & 4）**、**压缩后技能与锚点续接**、**Pi 原生角色读写提案工具（`read_team_roles` / `propose_role`）**、**资料空间指针式目录导入与消息保存持久化**，以及**技能与信任 / 运行洞察 / 角色架构师**全链路 Web 体验收口。

## 本版变化

- **信任四步完整闭环（步骤 3 & 4）与 Pi 原生发现 Skills 面板**：
  - 新增 `skill_trust_policies` SQLite 表与 ACL 隔离接口 `GET/PATCH /api/skills/trust`、`GET /api/skills/trust/detail`，在 `pa-extensions/skill-capture/pi/` 实现 Pi 原生 `tool_call` 脚本执行门禁（步骤 3 `confirm` 经 `ctx.ui.select` / `DialogBroker` 弹窗确认并支持一键升级步骤 4 `autonomous`；`disabled` 拦截并记录执行次数）。
  - 在 `@pa/pi-rpc` 新增 `PiRpcWorker.getCommands()` 与 `readPiDiscoveredSkills()`，在 **设置 → 技能与信任**（`SkillsTrustPanel`）左右分栏同屏展示 PA 托管技能与 Pi 原生发现技能（含 `pa-builtin`、本机与生态包 Skills），支持浮层只读预览 `SKILL.md` 与 `scripts/*`。
- **Pi 原生角色读写工具（`read_team_roles` / `propose_role`）与角色体验收敛**：
  - 在 `pa-extensions/worker-runtime` 注册 `read_team_roles`（读取当前可见角色名录与可选协作体检证据）和 `propose_role`（提议创建新角色及配套 `newSkills` 草案，或调整现有角色边界），任何非讨论主责角色（内置 `role-architect` 或用户导入的领域角色设计师）均可复用统一 `RoleProposalCard` 人工确认流。
  - 移除过时的手动建角色表单（`RoleArchitectModal.tsx`）与独立体检弹窗（`TeamHealthcheckPanel.tsx`），将「团队协作体检」收口为带体检上下文的 `role-architect` 持久化对话事项；优化两阶段澄清节奏、去重 `Anti-Jobs` 展示，并新增 `GET /api/members/:id/skills/detail` 支持角色详情页点击预览专属 Skill。
- **Pi 原生能力增强与三态本地资源继承策略**：
  - 新增 `pa-extensions/worker-runtime/pi/compaction-carryover.ts`（对接 `session_compact`）在长会话压缩后自动恢复已读 Skill 正文与资料/委托锚点；新增 `pi-extensions/next-steps` 与 `pa-extensions/next-steps`（`suggest_next_steps` 一键下一步建议）。
  - `PA_LOCAL_PI_RESOURCES` 升级为三态策略（`auto` | `1`/`always` | `0`/`off`），允许团队/认证/局域网宿主按需继承宿主机 `~/.pi` 生态包，同时保持托管克隆仓隔离；将独立 `meta-architect.ts`（`architect-aux`）工具收紧为只读 `read,grep,find,ls` 并同步对齐 `runtime-info` 展示。
- **资料空间目录导入与消息保存体验升级**：
  - `save_space_page` 新增指针式 `sourceDir` 目录导入（自动跳过噪音与敏感文件并全量原子校验）及工具级 `promptSnippet` / `promptGuidelines`。
  - 「保存文字到资料空间」支持就地选择目标空间（个人/组织/仓库/角色/自定义）与自动清理标题 Markdown，并通过 `sourceMessageId` 持久化写入消息 `metadata.spaceDocuments`，刷新页面后呈现标准 `SpaceDocumentCard` 不再重复触发保存。
- **运行洞察与复盘闭环**：
  - 将确定性 `session-insights` 发现与信任四步遥测接入 `collectTeamHealthEvidence`（严格租户隔离）；统一 `SessionInsightsPanel` 与 `SettingsView` 的字号、4 列指标卡与 3 列单行截断会话表排版，为「重新扫描」新增二次确认与真实耗时回显。

## 安装与升级

从 [GitHub Release](https://github.com/civaapple-alt/personal-agent/releases/tag/v0.8.1) 下载发布包。需要 Node.js 22.19 或更高版本和 Git；执行 AI 任务还需要安装并配置 Pi CLI。

| 文件 | 使用方法 |
| --- | --- |
| `personal-agent-0.8.1-prebuilt.tar.gz` | 解压后运行 `node apps/cli/dist/main.js` |
| `personal-agent-0.8.1-source.tar.gz` | 解压后运行 `npm ci` 和 `npm run start:web` |
| `SHA256SUMS` 和 `manifest.json` | 核对下载文件和发布提交 |

**从 0.8.0 / 0.7.x 升级**：可直接复用已有 `.data/` 数据目录，启动时自动初始化 `skill_trust_policies` 表，无需手工迁移。

安装步骤见[首次运行教程](../tutorials/getting-started.md)。
