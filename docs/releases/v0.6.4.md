# Personal Agent 0.6.4

统一对话不再切分“讨论模式”与“执行模式”，每个 AI 岗位直接以自身配置的工具、Skills 和 Human Question 连续工作；同时重构 Pi 扩展管理、接入按岗位授权的网页检索，并优化左侧栏事项组织、归档与新建事项体验。

## 本版变化

- **统一角色对话与执行。** 去掉统一输入框内的只读讨论与执行确认二分，主责在同事项工作区始终复用同一条持久 Pi 会话，直接按角色配置的工具与边界决定回复、查证、执行或调用 `request_clarification` 提请人类决定。前置路由收敛为实时名册查询、工作台速查上下文注入与无主责自动选人（支持 System One、隔离 Pi 决策与本地规则三级回退，预构建包内置决策 SDK）。 [统一消息路由](../reference/runtime-collaboration.md#统一消息路由) · [工作台功能速查](../guides/agent-workbench.md)
- **Human Question 独立扩展与决定卡优化。** 将澄清工具 `request_clarification` 抽离为独立的 `human-question` Pi 扩展；决定卡片去掉冗余占位气泡，用可点击选项胶囊 + 行内输入替代单选列表，并保留对历史执行确认卡的轻量兼容展示；工作台帮助支持交互式试用「待你决定」表单。 [等待人类决定](../reference/runtime-collaboration.md#等待人类决定)
- **Pi 原生包管理与按岗位网页检索。** 改用 Pi CLI 原生包发现与安装管理 `pstack` 与 `pi-web-access`，启动时检测 Pi CLI 版本；管理员可在设置页按岗位授予网页检索权限，独立于岗位对话模型运行。宿主侧扩展集成统一收口到 `src/pa-extensions/`。 [为 AI 岗位启用网页检索](../guides/web-search.md) · [启用 pstack 方法包](../guides/pstack-runtime.md)
- **左侧栏与新建事项体验优化。** 左侧事项统一收紧为单行（状态指示 + 标题 + 悬停组织/仓库提示），支持「时间 / 分组（按组织与仓库）」切换和逻辑归档/恢复；底部收口为单行（当前用户 + 运行状态 + 浮动「设置」菜单）；顶部角色超过 8 个自动折叠；`+` 新建事项默认选中当前组织主联系人，已有事项内点 `+ 新事项` 默认继承当前事项团队配置。 [工作台使用指南](../guides/user-guide.md)

## 安装与升级

从 [GitHub Release](https://github.com/civaapple-alt/personal-agent/releases/tag/v0.6.4) 下载发布包。两种安装方式都需要 Node.js 22.19 或更高版本。执行 AI 任务还需要安装并配置 Pi CLI。

| 文件 | 使用方法 |
| --- | --- |
| `personal-agent-0.6.4-prebuilt.tar.gz` | 解压后运行 `node dist/server/main.js` |
| `personal-agent-0.6.4-source.tar.gz` | 解压后运行 `npm ci` 和 `npm run start:web` |
| `SHA256SUMS` 和 `manifest.json` | 核对下载文件和发布提交 |

升级前停止旧服务，备份数据库、Pi 会话和自建资源，再用新版本打开原数据目录。 [首次运行](../tutorials/getting-started.md) · [备份说明](../guides/team-administration.md#保存与备份运行资料)
