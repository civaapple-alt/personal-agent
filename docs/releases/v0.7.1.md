# Personal Agent 0.7.1

0.7.1 深化了与 Pi 原生 Skill / 命令生态的集成，新增独立个人账号页与可收窄范围的 Access Token，并改进了工作区目录选择与运行期过程可观测性。

## 本版变化

- **原生 Pi Skills 与 `role-skills` 包**：移除旧 `pstack` 专属集成，将内置岗位方法封装为标准 Pi Package（`pi-extensions/role-skills`，终端 Pi 也可直接 `pi install`）；内置写作规范更名为 `deliverable-writing` 避免撞名遮蔽；`skill-catalog` 自动发现 Pi 已安装 Skills（含手动触发 Skill）与扩展命令，补齐 `source` 来源、去重 `<available_skills>` 并归一化 `/skill:` 前缀。
- **独立个人账号页与 Access Token**：点击左下角用户名进入独立 `#/account` 页面，支持生成只读（`read`）或完整（`full`）权限的个人访问令牌，默认继承当前账号范围，也可收窄到指定组织与工作区，支持有效期与即时吊销。
- **跨岗位共享运行工具与运行期证据**：跨岗位执行模式共享已配置运行工具与插件，移除按岗位单独开关 Web 访问；主责获得作用域团队能力卡，GitHub 抓取上报来源证据与临时克隆生命周期，对话内「执行过程」以单行方式展示每轮工具与 Skill 执行记录。
- **工作区与复盘工具**：工作区登记与附加目录支持服务端目录选择器；新增 `pa-matter-retrospective` 复盘技能与只读查询脚本（支持本机 loopback、PAT / 账号登录及 SQLite 只读回退）。

## 安装与升级

从 [GitHub Release](https://github.com/civaapple-alt/personal-agent/releases/tag/v0.7.1) 下载发布包。需要 Node.js 22.19 或更高版本和 Git；执行 AI 任务还需要安装并配置 Pi CLI。

| 文件 | 使用方法 |
| --- | --- |
| `personal-agent-0.7.1-prebuilt.tar.gz` | 解压后运行 `node dist/server/main.js` |
| `personal-agent-0.7.1-source.tar.gz` | 解压后运行 `npm ci` 和 `npm run start:web` |
| `SHA256SUMS` 和 `manifest.json` | 核对下载文件和发布提交 |

**从 0.7.0 升级**：可直接复用 0.7.0 的 `.data/` 数据目录，首次启动会自动补建 `user_access_tokens` 表，无需迁移旧库。从 0.6.x 及更早版本升级请先阅读 [0.7.0 发布说明](v0.7.0.md#安装与数据准备)。

安装步骤见[首次运行教程](../tutorials/getting-started.md)。
