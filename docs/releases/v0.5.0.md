# Personal Agent 0.5.0

发布日期：2026-11-16。本次为本地版本发布，版本号统一为 `0.5.0`，Git 标签为 `v0.5.0`。不推送远端，不发布 npm，保留 `private: true`。

## 本版范围

- 跨项目岗位团队：产品、研发、测试及市场营销四个示例岗位，可通过角色模板扩展。工作台提供事项讨论、真实内部委托、阶段成果和反馈修订。
- 连续上下文：按事项、成员、组织及仓库范围恢复确切 Pi 会话；中断后可在下一轮接续，并保留恢复简报。
- 岗位旁听：在主回复完成后审视讨论，按需补充或静默；独立会话、工具限制、后加入背景和关闭行为已有隔离演示。
- 正式成果：普通讨论不自动归档；显式发布形成版本。已保存文档通过 `sourcePath` 读取最终文件，提交前校验快照，避免文件与归档正文分叉。
- 组织与协作：组织及仓库背景隔离、轻量局域网协作、提请与派发状态校验、图片输入和事项成员设置。
- 基础 RSI：候选经验、无工具复盘、核验/替代、作用域注入和版本反馈关联；已有真实链路证据。
- 真实任务验证：当时的内置演示体验四步协作（该入口后来移除），`demo:review` 分层评估发布、场景协作与正文质量，`demo:observer` 检查旁听提醒、静默、接续和关闭。

完整变更记录见 [CHANGELOG](../../CHANGELOG.md)，模块及后续计划见[架构说明](../concepts/architecture-and-plan.md)。

## 本地发布包

在干净、已提交的版本上执行：

```bash
npm run package:release
```

依赖已通过 `npm ci` 安装时，脚本在临时源码快照中构建并验证，不使用用户运行数据。输出位于 `.releases/v0.5.0/`：

| 文件 | 用途 |
| --- | --- |
| `personal-agent-0.5.0-source.tar.gz` | Git 提交中的源码、岗位、Skills、文档和测试 |
| `personal-agent-0.5.0-prebuilt.tar.gz` | 相同源码快照及已构建的 `dist/`、`web/dist/` |
| `manifest.json` | 源提交、版本、文件大小、校验值及解压启动验证记录 |
| `SHA256SUMS` | 两个压缩包与 manifest 的 SHA-256 校验值 |

包内不包含 `.git/`、`.data/`、`.pi/`、`node_modules/` 或本地发布产物。重复打包同版本同提交时只核验已有产物；不同提交或校验异常不会覆盖旧包。

## 启动

运行环境为 Node.js ≥ 22.19、Git；AI 执行另需本机 Pi CLI 已配置模型访问。工作台启动与浏览不等于已经调用模型。

预构建包解压后，在其根目录运行，无须重新构建：

```bash
node dist/server/main.js
```

默认工作台地址为 `http://127.0.0.1:4310`。预构建包保留源码、岗位与 Skills，源码包则按以下方式准备：

```bash
npm ci
npm run build
node dist/server/main.js
```

升级时先停止旧服务并保留原 `.data/`、会话文件和已登记业务仓库；选择已有数据路径的方式见[配置参考](../reference/configuration.md)。发布包不携带、替换或重置用户数据。历史无组织来源的会话继续保留，新范围不猜测旧归属，具体接续规则见[运行说明](../reference/runtime-collaboration.md)。

## 验证与限制

本版离线基线为 107 项测试，并执行代码检查、构建、源码/编译入口隔离启动及文档检查。打包脚本还会在新解压目录、不带 `node_modules` 的情况下再次检查两个服务入口、网页、演示初始化和正常退出；这些验证不调用模型。

既有真实证据分别保留于[协作链路验证](../validation/runtime-checks.md)、[复核评估](../validation/publication-review.md)和[旁听演示](../validation/observer-demo.md)。本次发布不为版本号重复运行收费模型任务。评估场景仍有正文质量失败，不能把执行成功、咨询发生或版本数量当作内容验收。

尚未完成持久后台调度、多日自主运行、经对照证明的持续学习、完整人才市场、细粒度多组织访问控制或操作系统沙箱。旁听和文件一致性检查不构成自动语义质量门禁。
