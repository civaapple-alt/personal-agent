# Personal Agent 0.6.3

在同一个输入框里讨论、点名 AI 角色和交办工作。事项内可以查看本轮委托、处理待决定的问题，并打开当前事项的成果与历史版本。

## 本版变化

- **讨论和交办共用输入框。** 用 `@` 点名角色，请它查证或交办任务。执行意图不明确时，工作台显示「待你决定」。卡片记录答复人和答复内容，收到答复后可接续处理。协作者需要澄清时，先问委托者。 [安排事项](../guides/user-guide.md#在同一条对话里讨论和交办) · [等待人类决定](../reference/runtime-collaboration.md#等待人类决定)
- **按轮次查看协作与验收。** 委托公告板按编号保留任务、转派和回报，关系图可定位到原始消息。独立验收可绑定具体提交、工作区文件或文档草稿。运行中的停滞提醒显示成员和最近一次活动。 [查看每轮团队委托](../guides/user-guide.md#查看每轮团队委托)
- **在事项内创建角色和查阅成果。** 明确请求创建 AI 角色时，可在原对话调用角色架构师。角色提案由有权限的人确认，卡片记录确认者。最近事项标出组织和仓库，切换事项可恢复当前标签页中的未发送草稿。右上角的「成果库」显示本事项的最新成果和历史版本。 [工作台使用指南](../guides/user-guide.md)
- **集中设置模型默认值。** 角色定义保留职责与工具。供应商、模型和思考等级可在全局、组织岗位或事项中设置。模型列表支持按供应商筛选和按名称或 ID 搜索。 [调整岗位模型](../guides/user-guide.md#调整岗位模型)
- **接续已有 Pi 会话。** 成员、经验和目录清单更新时，工作台把新上下文追加到会话，尽量保留模型请求前缀。明确询问当前成员时，讨论使用实时名册。 [会话范围与接续](../reference/runtime-collaboration.md#会话范围与接续)

## 安装与升级

从 [GitHub Release](https://github.com/civaapple-alt/personal-agent/releases/tag/v0.6.3) 下载发布包。两种安装方式都需要 Node.js 22.19 或更高版本。执行 AI 任务还需要安装并配置 Pi CLI。

| 文件 | 使用方法 |
| --- | --- |
| `personal-agent-0.6.3-prebuilt.tar.gz` | 解压后运行 `node apps/cli/dist/main.js` |
| `personal-agent-0.6.3-source.tar.gz` | 解压后运行 `npm ci` 和 `npm run start:web` |
| `SHA256SUMS` 和 `manifest.json` | 核对下载文件和发布提交 |

升级前停止旧服务，备份数据库、Pi 会话和自建资源，再用新版本打开原数据目录。 [首次运行](../tutorials/getting-started.md) · [备份说明](../guides/team-administration.md#保存与备份运行资料)
