# Personal Agent 0.6.2

0.6.2 让本机任务沿用已有的 Pi 环境，并收紧工作区、经验和 SQLite 迁移的一致性。工作台也改进了导航、键盘焦点和运行时渲染。

## 本版变化

- 个人版仅监听回环地址时，本机所有者发起的业务执行沿用 Pi 用户级 Skills、已启用的扩展包，以及 Pi 信任的本地仓库 `.agents/skills` 和 `.pi/`。团队版、托管克隆和旁听继续显式装配资源。两种资源策略使用独立的 Pi 会话，可用 `PA_LOCAL_PI_RESOURCES=0` 切换为显式装配。 [资源配置](../reference/configuration.md#cli-启动与能力装配)
- 工作区设置和授权名单在同一事务保存。已有事项、经验、执行历史或授权名单的工作区保留组织归属。迁移采用版本号，修复旧库的部分外键并保留已有 Git 署名。经验核验维持单一有效替代项。 [存储与迁移](../../src/storage/README.md)
- 事项讨论失败时保留已交付状态和已保存的回复。切换组织主联系人时保留名册、模型和 Git 覆盖项。
- 工作台为跨页、成果版本和协作浮层提供过渡，支持减少动态效果设置和浏览器回退。运行计时由叶组件更新，侧栏独立于流式文本更新。
- 按职责拆分事项路由、网页 API、大型组件和样式。Pi RPC 拒绝同一工作进程的重叠提示执行。 [架构盘点](../concepts/architecture-and-plan.md#目录组织与源文件行数)

## 安装与升级

从 [GitHub Release](https://github.com/civaapple-alt/personal-agent/releases/tag/v0.6.2) 下载发布包和校验文件。

| 文件 | 使用方法 |
| --- | --- |
| `personal-agent-0.6.2-prebuilt.tar.gz` | 解压后运行 `node dist/server/main.js` |
| `personal-agent-0.6.2-source.tar.gz` | 解压后运行 `npm ci` 和 `npm run start:web` |
| `SHA256SUMS` 和 `manifest.json` | 核对下载文件和发布提交 |

两种方式都需要 Node.js 22.19 或更高版本。执行 AI 任务还需要安装并配置本机 Pi CLI。升级前停止旧服务，备份运行目录、Pi 会话和自建资源，再用新版本打开原数据库。遇到悬空外键时，升级会回滚并报告相关表与记录。 [首次运行](../tutorials/getting-started.md) · [备份说明](../guides/team-administration.md#保存与备份运行资料)

## 验证范围

本版在 macOS 上通过 178 项离线测试、静态检查、构建、源码与编译入口启动，以及文档检查。发布包另作解压启动验证。Pi 1.5.2 的本机资源发现使用临时目录实测，覆盖用户与仓库 Skills、已缓存 Git 扩展包和项目可信规则。浏览器走查在隔离团队沙盒中验证导航、成果版本、附件草稿和减少动态效果。以上检查范围为资源装配、应用行为和启动。 [跨平台 CI](https://github.com/civaapple-alt/personal-agent/actions/workflows/ci.yml) · [完整变更](../../CHANGELOG.md)
