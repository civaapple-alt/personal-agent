# Personal Agent 0.8.0

0.8.0 完成了面向 Pi 原生内循环的架构升级：确立**三环多包硬边界**与**双半边扩展体系**，将宿主专用桥接从便携 `pi-extensions/` 拆分独立为按需挂载的 `pa-extensions/*`，落地结构化可视化卡片（`visualize`）与面向「信任四步·第二步」的统一 Skill/脚本沉淀闭环（`propose_skill`），并在 Web 侧引入可扩展的 `toolRenderers` 与基础设施收口。

## 本版变化

- **三环硬边界多包架构与自动化门禁**：重构为 `packages/contracts`、`packages/pi-rpc`、`packages/extension-api`、`packages/extension-sdk`（外部扩展 API `1.0`）、`packages/server`、`apps/web` 与薄启动器 `apps/cli`，新增 `npm run check:boundaries` 强制校验跨环、前后端双半边、`packages/server` 内部单向依赖及便携 `pi-extensions/*` 隔离；`npm run build:cli` 产出自包含单文件 `apps/cli/dist/main.js`，使预构建包可在零 `node_modules` 环境下启动。
- **按能力拆分的 `pa-extensions/*` 与纯净 `pi-extensions/*`**：将原单体 `team-extension` 移出 `pi-extensions/` 并拆分为 5 个按权限按需挂载的独立宿主扩展包（`worker-runtime`、`workbench-help`、`space`、`delegation`、`skill-capture`），每个包严格分离 `pi/`、`server/`、`web/`；`pi-extensions/` 现仅保留可脱离 PA 独立运行的纯便携 Pi 扩展（`visualize`、`human-question`、`skill-catalog`、`role-skills`）。
- **Pi 原生工作流路由与统一 `propose_skill` 闭环**：新增 `pa-extensions/workflow`（`before_agent_start` 薄路由 Hook + `pa-team-collaboration` / `pa-space-deliverables` / `pa-trust-capture` / `pa-external-repo-evidence` 按需加载 Skills）；将模型侧复用沉淀收口为统一的磁盘 `propose_skill`（`SKILL.md` + 可选可执行 `scripts/*`），经 `SkillProposalCard` 人工确认后原子写入 `.data/skills/{global,orgs,users}/` 或 `<workspace>/.agents/skills/`，并在下一轮按组织/个人作用域自动通过 `--skill` 被 Pi 原生发现（历史 `member_memories` 数据无需迁移）。
- **确定性会话洞察（Session Insights）与渐进式自检 Skill 体系**：借鉴 JetBrains ThinkRail `@thinkrail/pi-session-insights`（Apache-2.0）落地零模型、零网络的本地 Pi 会话确定性体检引擎（自动识别反复失败命令、未加载的僵尸 Skill、单会话高频返工、连续重复工具调用、成本异常、未跑测试即宣称通过与跨会话重复指令，并内置路径与凭据脱敏）；新增租户隔离接口 `GET /api/runtime/insights`、Web **设置 → 运行洞察**面板、`pa-extensions/self-inspect` 渐进式自检技能包（含独立 `session-insights.mjs` CLI）以及 `inspect-matter.mjs --insights` 复盘联动。
- **结构化可视化扩展（`visualize`）与 Web `toolRenderers`**：移植改编 JetBrains ThinkRail 的 `@thinkrail/pi-visualize`（Apache-2.0，见 [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md)），提供零依赖便携 `pi-extensions/visualize` 与双半边 `pa-extensions/visualize`（支持 `table`、`kv`、`tree`、`timeline`、`diff`、`diagram`、`cards` 视图）；Web 侧新增 `toolRenderers` 扩展接缝、可参数化 API/SSE 端点、`ErrorBoundary` 视图级错误隔离与业务无关基础原语（`apps/web/src/primitives/`）。
- **服务端底层治理**：新增受控子进程执行器（`packages/server/src/subprocess`）与轮转结构化 JSONL 日志器（`packages/server/src/log`），统一运行时资产清单 `@pa/server/build-support`。

## 安装与升级

从 [GitHub Release](https://github.com/civaapple-alt/personal-agent/releases/tag/v0.8.0) 下载发布包。需要 Node.js 22.19 或更高版本和 Git；执行 AI 任务还需要安装并配置 Pi CLI。

| 文件 | 使用方法 |
| --- | --- |
| `personal-agent-0.8.0-prebuilt.tar.gz` | 解压后运行 `node apps/cli/dist/main.js` |
| `personal-agent-0.8.0-source.tar.gz` | 解压后运行 `npm ci` 和 `npm run start:web` |
| `SHA256SUMS` 和 `manifest.json` | 核对下载文件和发布提交 |

**从 0.7.x 升级**：可直接复用 0.7.x 的 `.data/` 数据目录，无需数据库迁移；历史 `member_memories` 表保持原样，新的复用沉淀通过 `propose_skill` 确认后直接写入 `.data/skills/` 或 `<workspace>/.agents/skills/`。从 0.6.x 及更早版本升级请先阅读 [0.7.0 发布说明](v0.7.0.md#安装与数据准备)。

安装步骤见[首次运行教程](../tutorials/getting-started.md)。
