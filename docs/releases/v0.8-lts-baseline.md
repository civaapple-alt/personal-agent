# Personal Agent 0.8.x LTS 候选基线说明

`0.8.x`（当前基线 `v0.8.2`）收敛为 Personal Agent 的 **LTS（长期支持）候选基线**。从 `0.8.0` 到 `0.8.2`，项目完成了向「**顺着 Pi 纹理生长：Roles 身份能力配置 + Skills 能力沉淀 + RSI 自我改进三层一体**」的架构收敛；后续 `0.8.x` 补丁版本聚焦稳定性、安全修复、回归缺陷与文档修正，不再引入破坏性存储或契约变更。

## 1. 0.8.x 冻结的稳定契约（Frozen Contracts）

以下边界与数据格式在 `0.8.x` 生命周期内保持向后兼容，不引入破坏性变更：

| 契约面 | 冻结范围 | 守护门禁 |
| --- | --- | --- |
| **三环多包边界** | `packages/contracts`（The Wire） / `packages/server`（Engine Host） / `apps/web`（UI Client） + `packages/pi-rpc` + 薄入口 `apps/cli` | `npm run check:boundaries`（300 文件） |
| **双半边扩展体系** | `pi-extensions/*`（零 `@pa/*` 依赖的便携 Pi 扩展）与 `pa-extensions/*`（严格分离 `./server` 与 `./web`）；对外 SDK `@pa/extension-sdk` 版本校验 | `npm run check:boundaries`、`test/extension-registries.test.ts` |
| **角色定义契约（`roles/*.md`）** | Markdown YAML frontmatter（`id`, `name`, `title`, `roleKind: business \| solo \| architect`, `thinking`, `roleScope`, `antiJobs`, `skills`, `mcpDependencies` 等）；岗位专业定义与运行态主责/内部/旁听解耦 | `test/role-management-tools.test.ts`、`test/role-architect.test.ts` |
| **存储与 Git Space 布局（`.data/`）** | SQLite `0x50413730` 基线 schema（0.7.0 / 0.8.0 / 0.8.1 → 0.8.x 自动幂等建表，零手工迁移）；五类默认 Git 资料空间（`.data/spaces/`）与 Pi `--session` JSONL 目录 | `packages/server/src/storage/database.ts`、`npm run check:startup` |
| **Pi 原生三层底座** | Roles（含 `Pi Default` 单兵与多岗位业务团队）+ Skills & Scripts（`propose_skill` + 紧凑分页 `skill-catalog`）+ RSI（确定性 `session-insights` + `Role Architect` 体检 + `tool_call` 信任四步门禁） | `npm test`（237 项）、实机 `demo:solo` / `demo:team:capabilities` / `demo:pstack` / `demo:pi-native` / `demo:trust` |

## 2. 0.8.x LTS 候选维护策略

- **0.8.x 允许合入（Patch Releases `0.8.3+`）**：
  - 安全修复与依赖漏洞修补（当前生产依赖 `npm audit --omit=dev` 0 漏洞）；
  - 回归缺陷修复、Prompt Cache 与上下文稳定性调优、测试覆盖加固；
  - 文档修正与发布说明维护。
- **留给 0.9+ 的演进方向（不在 0.8.x 引入破坏性改动）**：
  - 操作系统级执行沙箱 / 容器隔离；
  - 长期无人值守后台定时调度与跨重启自主自治；
  - 公开角色/技能市场与跨引擎外部 CLI 适配器。

## 3. 发布与验收基线检查清单

任何 `0.8.x` 补丁发布前必须通过全部离线门禁，并按改动面选择对应实机 Pi 冒烟：

1. **全量离线门禁**：
   - `npm run check`（`lint` + `typecheck` + `check:boundaries` + `check:css`）
   - `npm run build`（CLI 自包含单文件 + Web 静态产物）
   - `npm test`（全量离线单元测试）
   - `npm run check:startup`（源码与预构建双入口 × 文件/内存库 4 项启动与优雅关闭验证）
   - `npm run check:docs`（全仓 Markdown 链接、命令引用与导航可达性）
   - `npm run check:opensource`（开源合规与敏感信息扫描）
   - `npm run package:release`（隔离构建与产物 SHA256 打包自检）
2. **实机 Pi 冒烟（按改动面必跑）**：
   - 涉及角色上下文/单兵隔离：`npm run demo:solo`
   - 涉及团队能力卡/委托：`npm run demo:team:capabilities`
   - 涉及 `skill-catalog` / `pstack`：`npm run demo:pstack -- --source <pstack路径>`
   - 涉及 `<pa_docs>` / `visualize` / `next-steps` / 信任四步：`npm run demo:pi-native`、`npm run demo:trust`
