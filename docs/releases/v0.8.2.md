# Personal Agent 0.8.2

0.8.2 确立了「**顺着 Pi 纹理生长：Roles 身份能力配置 + Skills 能力沉淀 + RSI 自我改进三层一体**」的演进方向，围绕「喂养而不自造（Influence by feeding, never by assembling）」完成单兵 `Pi Default` 轨道、上下文与 Prompt Cache 深度优化、多角色协作纪律升级、角色定义与运行态解耦以及 Skill / 团队分栏浏览体验收口。

## 本版变化

- **单兵模式（`Pi Default`）与双轨协作边界清晰化**：
  - 新增内置单兵角色 [roles/pi-default.md](../../roles/pi-default.md)（`roleKind: "solo"`），关闭 `delegate_to_member` 与多角色团队话术，保留原生 Pi 终端直连手感及 PA 扩展能力（Space / `propose_skill` / `visualize` / `request_clarification` / `suggest_next_steps` / `read_team_roles` / `propose_role`），可零冲突搭配 `pi-subagents` 等原生 Pi 生态包。
  - 将 `solo` 正式升格为与 `business`、`architect` 并列的一等隔离类型：不截胡自动业务路由、建单自动收敛为单人阵型且关闭旁听、不污染业务团队体检（RSI）与前端协作者池；新增 [单兵模式与团队协作模式](../concepts/solo-and-team-modes.md) 与实机对比脚本 `npm run demo:solo`。
- **上下文压降与 Prompt Cache 稳定化**：
  - 团队能力卡改为**极简缓存稳定索引 + 按需加载**（`buildCompactTeamCapabilities` + `read_team_roles({ includeCapabilities: true })`），去掉每轮内联的易变时间戳与全量 5.5k 字符能力卡（实机 `product-manager` `PA_TURN_CONTEXT` 压降约 70%）。
  - 精简 `pi-extensions/skill-catalog`：移除无 TUI 的 RPC 环境下低收益高风险的 `list_pi_commands` / `request_pi_command` 工具；`before_agent_start` 切换为单行紧凑索引（空集零注入、上限 `6,500` 字符、截断显式标出 `hasMore=true` 与续页提示）；`list_available_skills` 新增 `query` / `source` / `offset` / `limit` 过滤分页与 `hasMore` / `nextOffset` 返回，非重名 Skill 默认省略绝对路径。
- **多角色协作纪律、岗位解耦与 Skill 编写标准**：
  - 将 4 个内置业务角色定义（`product-manager` / `engineering-manager` / `qa-manager` / `marketing-lead`）中的运行态主责/内部/旁听引导剥离，统一由 `prompts.ts` 按当前 `sessionMode` 动态注入 `## Matter lead coordination` 等段落。
  - 强化 QA Manager、独立验收（`verifier`）与旁听席（`observer`）的**按证据过滤 + P0/P1/P2 裁决规范**；支持角色模板可选默认 `thinking` 档位；为 `delegate_to_member` 增加 fail-closed 的 Space 文档交接预检（`handoffDocumentIds`）。
  - 新增便携 Skill [skill-design](../../pi-extensions/role-skills/skills/skill-design/SKILL.md)、[team-review-loop](../../pi-extensions/role-skills/skills/team-review-loop/SKILL.md) 及仓库级实机调优 Skill [.agents/skills/pa-pi-runtime-tuning/SKILL.md](../../.agents/skills/pa-pi-runtime-tuning/SKILL.md)。
- **角色架构师文件化与 Web 工作台分栏体验升级**：
  - 提取 [roles/role-architect.md](../../roles/role-architect.md) 与普通内置角色并列，移除专用侧边栏架构师横幅与特殊入口，统一以标准事项开展角色设计。
  - 升级 **AI 团队**（`TeamView`）与 **设置 → 技能与信任**（`SkillsTrustPanel`）为左导航 + 右内容分栏视图，支持完整 Skill 目录文件树预览（`SKILL.md`、`scripts/*`、`references/*` 等，含 Markdown 渲染/源码切换）与 Pi 原生发现技能只读预览（`GET /api/skills/trust/native-detail`）。
  - 新增零依赖 CSS 类名静态门禁 `npm run check:css`（接入 `npm run check`）并补齐全部缺失样式类。

## 安装与升级

从 [GitHub Release](https://github.com/civaapple-alt/personal-agent/releases/tag/v0.8.2) 下载发布包。需要 Node.js 22.19 或更高版本和 Git；执行 AI 任务还需要安装并配置 Pi CLI。

| 文件 | 使用方法 |
| --- | --- |
| `personal-agent-0.8.2-prebuilt.tar.gz` | 解压后运行 `node apps/cli/dist/main.js` |
| `personal-agent-0.8.2-source.tar.gz` | 解压后运行 `npm ci` 和 `npm run start:web` |
| `SHA256SUMS` 和 `manifest.json` | 核对下载文件和发布提交 |

**从 0.8.0 / 0.8.1 / 0.7.x 升级**：可直接复用已有 `.data/` 数据目录，无需手工迁移。

安装步骤见[首次运行教程](../tutorials/getting-started.md)。
