# Personal Agent 0.7.0 发布准备

0.7.0 正在准备，尚未发布。当前开发版以新的资料空间和全新数据目录为基础。

## 主要变化

- 资料空间使用独立 Git 仓库存放文档和修订，支持目录、预览、按版本反馈以及与事项、岗位经验关联。
- 人类协作使用账号和组织成员关系；岗位模型按事项、组织岗位和平台默认配置选择。
- 数据库从当前完整结构初始化，不提供历史数据库、旧成果或旧目录布局的自动迁移。

## 数据准备

停止服务后，先备份现有数据库、Pi 会话、资料空间和其他运行资料。为 0.7.0 指定一个新的空数据目录；不要删除或覆盖现有 `.data/`。旧数据需要通过对应版本访问。数据目录、备份内容和路径配置见[团队工作台管理](../guides/team-administration.md#保存与备份运行资料)及[配置参考](../reference/configuration.md)。

## 验证与发布

发布前应在目标平台验证检查、构建、完整离线测试、启动和打包，并在隔离数据目录验证实际工作流。真实 Pi 模型调用和跨平台运行须分别验证，不能由离线测试代替。发布包、标签和下载地址待正式发布时确定。
