# Personal Agent 0.7.0

0.7.0 以 Git 资料空间为基础组织文档、修订和团队反馈，更新了组织协作、工作区和 AI 岗位体验。

## 本版变化

- 资料空间支持分类文档、目录与文件、历史版本、静态预览和按版本反馈，文档可以关联事项与岗位经验。
- 组织管理人类成员、邀请、AI 岗位和主联系人。工作区支持多个目录及其 Rules、Skills。
- AI 团队支持岗位委托、旁听和独立验收，并按调用类型收窄工具、扩展和会话范围。Pi 以服务账号权限运行，不是操作系统沙箱。
- 移除内置反馈箱演示及旧成果存储，使用资料空间文档和反馈。

## 安装与数据准备

从 [GitHub Release](https://github.com/civaapple-alt/personal-agent/releases/tag/v0.7.0) 下载发布包。需要 Node.js 22.19 或更高版本和 Git；执行 AI 任务还需要安装并配置 Pi CLI。

| 文件 | 使用方法 |
| --- | --- |
| `personal-agent-0.7.0-prebuilt.tar.gz` | 解压后运行 `node dist/server/main.js` |
| `personal-agent-0.7.0-source.tar.gz` | 解压后运行 `npm ci` 和 `npm run start:web` |
| `SHA256SUMS` 和 `manifest.json` | 核对下载文件和发布提交 |

**0.7.0 不能直接使用或自动迁移旧版本数据库和旧资料目录。**停止旧服务后，备份现有数据库、Pi 会话、资料空间和其他运行资料，为 0.7.0 指定新的空数据目录。不要删除或覆盖现有 `.data/`；需要访问旧数据时使用对应的旧版本。数据目录和备份方法见[团队工作台管理](../guides/team-administration.md#保存与备份运行资料)及[配置参考](../reference/configuration.md)。

安装步骤见[首次运行教程](../tutorials/getting-started.md)。
