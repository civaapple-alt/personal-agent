# Personal Agent 0.9.0

Personal Agent 0.9.0 正式引入 **Board 多 Agent 异步协作模式（M1–M5）**、**SQLite 协作存储拆表与无损迁移（`user_version = 900`）**、**`Lead ↔ Board` 单事项双模式贯通**、**三包对齐的便携 Pi 协作扩展（`pi-extensions/board`、`pi-extensions/delegation`、`pi-extensions/roles`）** 以及**两级 `e2e/` 真实浏览器与受控实机端到端验证框架**，同时保持与 `0.8.x` / `0.7.x` 既有 `.data/` 数据目录自动升级兼容。

## 本版变化

- **Board 多 Agent 异步协作与 `Lead ↔ Board` 双模式贯通（M1–M5）**：
  - 支持在新建事项或单事项内切换并贯通 `lead` 与 `board` 协同模式（[mode-handoff.ts](../../packages/server/src/orchestrator/execution/mode-handoff.ts)）：由常驻 `Coordinator` 通过 `spawn_board_agent` 动态组队并指定 `ownedScope` 与可选异构验证模型 `modelOverride`，借助 `last_read_post_no` 增量游标摘要唤醒、`post_to_board` / `read_board_post` 懒加载、`edit`/`write` 工具屏蔽防自审、HITL `clarification @user` 暂停及 `@monitor` 静默巡检闭环协作。
  - 上线 3 层 Board 工作台面板 `MatterBoardPane`（含按状态分组的成员栏、`BotFaceIcon`、`waiting` 状态热切换 `modelOverride`、可筛选板帖流、`@mention` 快捷发帖、分页事件时间线及轻量 SVG `关系图` 视图），并与 `/api/events` 主 SSE 流合流以支持 `隐藏非活跃` 与非 Coordinator 成员一键退场；打通 `verify_rework`、`escalate` 与 `monitor_alert` 信号进入 `team-health` 与 `session-insights` 的 CoE × 四步信任 RSI 闭环，新增 `npm run demo:board`。
- **便携 Pi 协作扩展与默认岗位单一事实源（P-0907）**：
  - 将 `board`、`delegation` 与 4 个默认业务岗位定义（`product-manager`、`engineering-manager`、`qa-manager`、`marketing-lead`）收敛为可独立安装、双后端路由的便携 Pi 包（[pi-extensions/board](../../pi-extensions/board/index.ts)、[pi-extensions/delegation](../../pi-extensions/delegation/index.ts)、[pi-extensions/roles](../../pi-extensions/roles/index.ts)），在 PA 宿主模式下通过 `PA_TEAM_BRIDGE_URL` 接入租户权限与 SQLite 持久化，在原生 `pi` 控制台模式下自动切到 `.pi/` 本地持久化与隔离 RPC 子进程。
  - 统一增强控制台自然语言交互与开箱引导：`board` 与 `delegation` 均内置对应工作流 Skill（[board-collaboration](../../pi-extensions/board/skills/board-collaboration/SKILL.md) 与 [lead-delegation](../../pi-extensions/delegation/skills/lead-delegation/SKILL.md)），通过 `pi -e <package-dir>` 或 `pi install` 传包目录加载时随 `package.json` `pi.skills` 自动注册；同时支持 `/board <目标>`、`/delegate <自然语言任务>` 与 `/roles` 斜杠命令及 `promptGuidelines` 语义路由，并统一规范全部 8 个 `pi-extensions/*` README（PA 宿主与 `solo` 模式保持工具隔离与干净上下文）。
- **两级 `e2e/` 端到端验证框架与运行账本**：
  - 引入基于 Playwright 的隔离无模型浏览器端到端套件 `npm run e2e`（不调用外部模型、不触碰 `.data/`），覆盖个人工作台、Board 多层面板与实时 SSE、`Team Edition` 多租户 RBAC 场景。
  - 新增显式 opt-in 的全栈实机浏览器测试 `npm run e2e:browser:live`（`.data-e2e/runs/<NNN>-.../` 与 `runs.jsonl` 账本）及受控成本的多模型实机命令行调度器 `npm run e2e:live`（`PA_E2E_ALLOWED_PROVIDERS` 白名单与配置档选择）。
- **存储拆表、数据库参考文档与历史内存引用清理**：
  - 完成 `@pa/contracts` 领域 DTO 与 SSE 事件契约收口，将 SQLite `matter_messages` 中的系统事件、协作板帖与动态成员拆分至 `matter_events`、`matter_board_posts`、`matter_board_members`（`user_version = 900` 无损幂等回填迁移），补齐完整 [SQLite 库表设计参考](../reference/database-schema.md)，并清理现行文档中残留的旧版 SQLite 经验表引用。

## 安装与升级

从 [GitHub Release](https://github.com/civaapple-alt/personal-agent/releases/tag/v0.9.0) 下载发布包。需要 Node.js 22.19 或更高版本和 Git；执行 AI 任务还需要安装并配置 Pi CLI。

| 文件 | 使用方法 |
| --- | --- |
| `personal-agent-0.9.0-prebuilt.tar.gz` | 解压后运行 `node apps/cli/dist/main.js` |
| `personal-agent-0.9.0-source.tar.gz` | 解压后运行 `npm ci` 和 `npm run start:web` |
| `SHA256SUMS` 和 `manifest.json` | 核对下载文件和发布提交 |

**从 `0.8.x` / `0.7.x` 升级**：可直接复用已有 `.data/` 数据目录，服务启动时会自动执行无损且幂等的 SQLite `user_version = 900` 表结构升级与历史数据回填，无需手工迁移。

安装步骤见[首次运行教程](../tutorials/getting-started.md)。
