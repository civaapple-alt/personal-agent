# Personal Agent 0.6.0 开源准备

状态：**准备中，尚未发布**。目标版本为 `0.6.0`，项目原创代码、岗位定义和文档采用 [MIT](../../LICENSE)。版本元数据与 lockfile 已同步；最近正式的本地标签仍为 `v0.5.0`。本轮不创建 `v0.6.0` 标签、不推送远端、不发布 npm，也不覆盖旧发布包。

`package.json` 保留 `private: true`，防止误发 npm；它不限制 MIT 源码的使用。版权署名为 `Personal Agent contributors`。第三方代码、改编方法和素材范围以[第三方说明](../../THIRD_PARTY_NOTICES.md)为准。

## 拟纳入本版的范围

- 延续 0.5.0 的岗位团队、会话接续、真实内部委托、旁听、显式阶段成果和基础经验链路。
- 补充角色架构师、角色管理一致性、能力目录和依赖状态、模型阵型建议及角色设计。
- 可选 pstack 内循环：读取完整外部方法包的模式、playbook 与原则，维持岗位及事项工具权限。
- 增加真实岗位任务和自然方法选择验证，并保留失败结果。最新自然任务基线中五个专门目标 Skill 均未被观察到；四项答复审阅通过、一项技术设计失败，不能宣传为稳定自主方法选择或岗位质量提升。
- 补齐 MIT 许可证、pstack 改编归属、浏览器依赖许可、私有文件保护及可重复的开源准备检查。

仍不包含长期后台自治、完整 RSI、公开人才市场、自动插件安装或所有跨宿主能力适配。当前范围及限制见[架构说明](../architecture-and-plan.md)。

## 许可与素材边界

本地 `technical-writing` 改编自 pstack；第三方说明保留 `Copyright (c) 2026 Lauren Tan` 及 MIT 全文。浏览器包包含 React、React DOM 和 Scheduler，对应 Meta Platforms 的 MIT 全文也已保留。网页构建会把项目许可证与第三方说明复制到 `web/dist/`，便于单独分发网页构建物时保留声明。

完整 pstack 包由操作者另行配置，Pi 是外部运行底座，均不随本项目捆绑或重新授权。构建和开发依赖的许可信息保留在 lockfile 与其安装包中。

三个官方 Grok Bot 参考图的再分发许可尚未确认，它们不属于项目 MIT 授权。当前做法为：

- 保留本地文件与 Git 历史，保护研究过程。
- 文档使用官方资源链接。
- 通过 `.gitattributes` 的 `export-ignore` 排除这三张图，不进入 `git archive` 及由它生成的发布包。
- V1–V4 项目原型不受此排除规则影响，仍保留在源码归档中。

**公开完整 Git 仓库与分发导出快照是两件事。** `export-ignore` 不会从 Git 历史或推送中移除素材。公开现有完整历史前，仍需确认这些素材的权限与范围；也可从审核后的源码快照准备新的公开仓库。本轮未改写历史或配置远端。

## 可重复检查

在 Git 工作目录中运行：

```bash
npm run check:opensource
npm run check:opensource -- --history
npm run check:opensource -- --history --public
```

检查器只读当前 Git 跟踪文件及可选的可达历史对象，核对 MIT/版本元数据、私有或生成文件路径及有限密钥模式。匹配时只输出类别、位置和对象 ID，不打印凭据值。它不扫描用户 `.data/`、未跟踪文件或外部业务仓库，也不调用网络或模型。

`--public` 还会对当前仓库中的待审参考图返回非零退出码。这是本项目的准备阶段保护规则，不是对素材权利的法律判定。基础模式通过并不表示完整历史已经审完或可以直接公开；提交署名、业务上下文及不在检测模式内的凭据仍需人工核对。

开发者绝对路径和先前试用项目的名称已从当前公开说明中泛化；旧提交保留原记录。本轮首次历史检查未命中所检查的密钥模式，数量及最新状态以命令输出为准。

本轮已通过 `npm run check`、`npm run build`、150 项离线测试、四种入口与数据库组合的启动检查，以及文档链接检查。许可证检查已对照实际安装的 React、React DOM、Scheduler 声明，网页构建目录中的两份声明与根文件一致。以上检查未调用真实模型，不证明岗位自主能力或成果质量有提升。`--public` 仍因三张待审参考图返回非零，不能把基础检查通过解释为完整仓库已具备公开条件。

准备期间可以在干净、已提交的快照上生成独立预览包：

```bash
npm run package:release -- --preview
```

输出位于 `.releases/previews/v0.6.0-<提交前缀>/`，包含源码包、预构建包、manifest 与 SHA256SUMS。脚本验证版本、许可证、构建与解压启动，不自动对外发布，不占用 `.releases/v0.6.0/` 的正式产物目录。同一提交再次执行只核验已有包，不覆盖。

确认正式发布范围后，再沿[本地打包流程](../../scripts/README.md)生成正式目录下的本地发布包。预览包存在不代表已经创建版本标签或公开发布，也不表示完整 Git 历史已经完成素材审核。

面向新使用者的起点是[首次运行](../getting-started.md)，贡献入口为[贡献指南](../../CONTRIBUTING.md)，本机权限和网络暴露见[安全说明](../../SECURITY.md)。文档补充不改变当前运行能力，也不重置历史验证结果。
