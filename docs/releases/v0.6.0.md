# Personal Agent 0.6.0

0.6.0 是 Personal Agent 的首个公开版本，Git 标签为 `v0.6.0`。项目原创代码、岗位定义和文档以 [MIT](../../LICENSE) 发布。

## 下载和启动

从 [GitHub Release](https://github.com/civaapple-alt/personal-agent/releases/tag/v0.6.0)下载所需文件。

| 文件 | 用途 |
| --- | --- |
| `personal-agent-0.6.0-source.tar.gz` | 源码。解压后执行 `npm ci` 和 `npm run start:web` |
| `personal-agent-0.6.0-prebuilt.tar.gz` | 包含编译后的服务端和网页。解压后执行 `node dist/server/main.js` |
| `SHA256SUMS` | 两个归档和 manifest 的 SHA-256 校验值 |
| `manifest.json` | 发布提交、构建环境和解压启动检查结果 |

两种安装方式都要求 Node.js ≥ 22.19。执行 AI 任务还需要安装本地 Pi CLI 并配置模型。项目包保留 `private: true`，通过 GitHub Releases 分发。首次启动、团队权限和旧数据迁移见[安装与首次运行](../getting-started.md)。

## 本版变化

- 新增团队账号、注册审核、超管控制台、组织 RBAC 和项目、事项、附件及实时事件的访问控制。普通账号创建事项时可使用其默认或首个所属组织。
- 角色和 Skill 支持平台通用、组织共享和个人私有作用域。新 Skill 在用户确认后写入，同名冲突保留已有内容。
- 内置角色和 Skill 使用英文指令。保留中文岗位路由别名和旧版中文模板导入，回复和成果语言跟随用户请求。
- 角色架构师支持按流程规划角色、团队体检和事项中途补人。立项可选本地规则建议或 Pi 阵型决策。
- 扩展设置支持克隆、启用和更新完整 pstack 方法包。更新先校验候选版本，也可由 `PA_PSTACK_DIR` 指定已有目录。见[pstack 运行说明](../pstack-runtime.md)。
- 工作台增加个人版和团队版标识、运行设置、文本与代码附件，以及长粘贴折叠。

延续 0.5.0 的事项会话接续、真实内部委托、定向旁听、阶段成果和基础经验链路。长期后台自治、完整 RSI、公开人才市场和通用插件依赖安装仍在当前范围之外。Pi、工具和预览以宿主机账户权限执行，部署前阅读[运行与安全边界](../../SECURITY.md)。

## 公开历史与许可

公开仓库保留此前的每笔提交。历史发布副本移除了本地原型、研究笔记、未确认分发许可的 Grok Bot 参考图和私有路径，并使用 GitHub noreply 提交邮箱。受清理影响的提交 ID 会变化。本地原始提交、原型及研究笔记继续保留。

`technical-writing` 改编方法、React、React DOM 和 Scheduler 的版权与许可说明随包分发。归档中的授权范围见[第三方说明](../../THIRD_PARTY_NOTICES.md)。Pi 和完整 pstack 包单独安装。

## 验证范围

发布快照在 macOS 上运行静态检查、构建、161 项离线测试、文档检查和公开历史检查。正式归档另做解压启动验证，覆盖源码和编译入口的文件库及内存库组合。Linux、macOS 和 Windows runner 的检查结果见 [GitHub Actions](https://github.com/civaapple-alt/personal-agent/actions)。

发布检查不调用真实模型。此前五项自然任务中均未观察到预期的专门 pstack Skill，独立答复评审四项通过、一项失败。观察记录见[自然任务验证](../pstack-selection.md)。

完整变更见 [CHANGELOG](../../CHANGELOG.md)。普通问题可提交至 [GitHub Issues](https://github.com/civaapple-alt/personal-agent/issues)，安全问题按[私密漏洞报告流程](../../SECURITY.md#报告安全问题)处理。
