# Personal Agent 0.6.1

0.6.1 改进团队讨论、事项协作和成果库。项目沿用 [MIT 许可证](../../LICENSE)。

## 本版变化

- 按需请教和旁听把关分别配置。同一岗位可以同时参与，两类设置也可单独取消。切换到「一人处理」会保留已选旁听。
- 团队聊天可主动开启 AI 参与，并用 `@` 点名在组角色。已有事项升级后默认关闭。讨论使用独立 Pi 会话，保留岗位配置的查证工具。正式成果和经验提案由执行轮次处理。
- 成果库可按组织、仓库和访问范围筛选。事项发起人及具备管理权限的账号可以调整成果所继承的事项可见性。
- 支持按组织设置 AI 主联系人。AI 的 Git 提交默认使用目标仓库的 Git 署名，组织可显式启用角色署名和覆盖项。
- Pi 读取目标工作区的上下文。内嵌或克隆到宿主仓库下的业务仓库不会自动继承宿主的 `AGENTS.md`。
- 开发者可启动包含多组织、多账号和样本成果的[团队沙盒](../development.md#团队版一键验证沙盒)，使用临时数据验证页面和权限。

## 安装与升级

从 [GitHub Release](https://github.com/civaapple-alt/personal-agent/releases/tag/v0.6.1)下载源码包、预构建包及 SHA-256 校验文件。

| 文件 | 启动方式 |
| --- | --- |
| `personal-agent-0.6.1-prebuilt.tar.gz` | 解压后运行 `node dist/server/main.js` |
| `personal-agent-0.6.1-source.tar.gz` | 解压后运行 `npm ci` 和 `npm run start:web` |

两种方式都需要 Node.js ≥ 22.19。执行 AI 任务前需安装并配置本地 Pi CLI。升级前先停止旧服务，备份运行目录和会话，再由新版本打开原数据库。详见[首次运行](../getting-started.md)和[保存与备份运行资料](../user-guide.md#保存与备份运行资料)。

## 验证

发布快照在 macOS 上通过 167 项离线测试、静态检查和构建。发布包解压后通过源码与编译入口的启动检查。团队沙盒的 Chrome 验证覆盖了请教与旁听的双选、保持旁听的范围切换及键盘点名。这些检查使用离线 Worker 或临时数据。跨平台结果见 [GitHub Actions](https://github.com/civaapple-alt/personal-agent/actions/workflows/ci.yml)。
