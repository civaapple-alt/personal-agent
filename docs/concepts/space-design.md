# 资料空间设计

资料空间汇集团队在事项中形成的计划、过程资料和结果。资料可以持续编辑，所处阶段由内容和使用者决定。历史成果保留版本、反馈和经验关联。

## 使用方式

- 在空间中新建资料，选择所属事项，填写标题和正文。资料可在工作进行时保存、阅读和修改。
- 在事项对话中将有价值的内容保存为空间资料，或让岗位在工作中创建和更新资料。
- 从事项打开相关资料，也可以在空间按组织、仓库、事项查找。已有成果和历史版本继续可见。
- 更新资料时保留作者和历史，并避免两个用户互相覆盖。内容变更通知只发送给有权访问该事项的用户。

## 模型和边界

空间资料有独立身份、标题、正文、所属事项、创建及更新时间和修订号。资料的读取和写入分别沿用事项的读取与参与权限。修订使用预期版本检查，冲突时保留已保存内容并提示重新加载。资料与事项同时清理。

岗位使用 `save_space_page` 保存资料；回合成功后，本轮资料形成交互成果并关联反馈记录。成功执行的 `write`、`edit` 对工作区内 Markdown 与文本文件的修改也会在回合结束时收录。历史成果版本、反馈和经验引用继续使用原记录，已有数据无需迁移为可编辑资料。

岗位访问空间时由宿主提供受事项约束的工具。写入在宿主校验作用域和调用者能力。AI 写入与人类编辑都处理并发冲突。保存工具明确表示即时保存，后续轮次失败不会撤销已经成功的保存。

## 范围与演进

当前设计以事项作为资料的权限和来源边界。跨事项共享、页面层级、文件附件、富媒体和自动维护需要独立设计，不能通过复制私密正文来绕过原事项访问控制。空间保留历史成果的原有记录。
